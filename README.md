This repository contains a **Sales Dashboard** built in **Power BI**. The dashboard provides a comprehensive analysis of sales data, helping businesses monitor performance and make data-driven decisions.

## Features

- **City-Wise Sales**: Analyze sales distribution across various cities.
- **Monthly Sales Trends**: Track sales performance on a monthly basis.
- **Daily Sales Trends**: Understand sales activity for each day.
- **Weekly Sales Patterns**: Visualize sales distribution across the week.
- **Sales by Weekend**: Compare sales on weekends versus weekdays.
- **Top 5 Products by Sales**: Identify the products generating the highest revenue.
- **Top 5 Best-Selling Products**: Highlight the products with the highest units sold.
- **Top 5 Cities by Sales**: List the cities contributing the most to sales.
- **Product-Level Insights**: Detailed breakdown of sales by individual products.

## Methodology

1. **Data Preparation**:
   - Cleaned and organized the raw sales data.
   - Added calculated fields for monthly and weekly trends.
   - Created categories for weekend and weekday sales analysis.

2. **Data Modeling**:
   - Built a data model in Power BI to establish relationships between tables.
   - Optimized the model for better performance and faster querying.

3. **Dashboard Design**:
   - Used Power BI's interactive visuals to create intuitive and informative charts.
   - Implemented slicers for dynamic filtering by city, product, and time.

4. **Testing and Validation**:
   - Validated the dashboard's accuracy by cross-checking against source data.
   - Ensured the visuals respond interactively and provide actionable insights.
